## [0.1.0] - 2026-10-09

### Added

- Retrieve and deploy source from Explorer, editor context menus, and the command palette.
- Delete metadata from the org only, or from both the project and org.
- Single-project and multi-root workspace support with selected-resource project resolution.
- Project-local default org isolation, same-project multiselect, and official Salesforce component resolution.
- Retrieve overwrite warnings, destructive-operation confirmation, and explicit conflict-overwrite consent.
- Dirty-editor save prompts, per-project operation locks, CLI JSON output, and unfinished-job handling.
- Automated tests, VS Code extension-host smoke tests, VSIX packaging, and tag-driven GitHub/Marketplace release workflows.
